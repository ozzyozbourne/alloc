# RAD Scratch Arenas

Rust port of RAD Debugger `base_thread_context.c`, built on `std::alloc::Allocator` (stable in Rust 1.100).

Per-thread scratch arenas for temporary work.

`with_scratch(|arena| ...)` replaces the C `conflicts` list: a borrowed arena is skipped automatically, and scratch data cannot escape.

**Open [`guide.html`](guide.html) for the full study guide**: the C and Rust code side by side, the differences, how to use it, and how to build it yourself.

| Path | What |
|---|---|
| `src/` | The Rust allocator (crate `rad_scratch`) |
| `original-c/` | The C it copies: `original-c/base_thread_context.{h,c}`, with its licence |
| `examples/` | Runnable demo |
| `tests/` | Tests |
| `guide.html` | The guide (generated by `tools/gen_guides.py`) |

```sh
cargo test -p rad_scratch
cargo run -p rad_scratch --example demo
```
