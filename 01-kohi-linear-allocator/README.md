# Kohi Linear Allocator

Rust port of Kohi `linear_allocator.c`, built on `std::alloc::Allocator` (stable in Rust 1.100).

A bump allocator over one fixed block, reset all at once with `free_all`.

Adds alignment (C has none); `free_all(&mut self)` makes use-after-reset a compile error.

**Open [`guide.html`](guide.html) for the full study guide**: the C and Rust code side by side, the differences, how to use it, and how to build it yourself.

| Path | What |
|---|---|
| `src/` | The Rust allocator (crate `kohi_linear`) |
| `original-c/` | The C it copies: `original-c/linear_allocator.{h,c}`, with its licence |
| `examples/` | Runnable demo |
| `tests/` | Tests |
| `guide.html` | The guide (generated by `tools/gen_guides.py`) |

```sh
cargo test -p kohi_linear
cargo run -p kohi_linear --example demo
```
