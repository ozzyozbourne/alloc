# RAD Arena

Rust port of RAD Debugger `base_arena.c`, built on `std::alloc::Allocator` (stable in Rust 1.100).

A chained, virtual-memory-backed arena (mmap reserve, mprotect commit) with `Temp` scopes.

Popping takes `&mut self`, so use-after-pop is a compile error; the top allocation grows in place.

**Open [`guide.html`](guide.html) for the full study guide**: the C and Rust code side by side, the differences, how to use it, and how to build it yourself.

| Path | What |
|---|---|
| `src/` | The Rust allocator (crate `rad_arena`) |
| `original-c/` | The C it copies: `original-c/base_arena.{h,c}`, `original-c/linux_base_memory_excerpt.c`, with its licence |
| `examples/` | Runnable demo |
| `tests/` | Tests |
| `guide.html` | The guide (generated by `tools/gen_guides.py`) |

```sh
cargo test -p rad_arena
cargo run -p rad_arena --example demo
```
