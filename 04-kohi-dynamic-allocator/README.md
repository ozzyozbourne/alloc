# Kohi Dynamic Allocator

Rust port of Kohi `dynamic_allocator.c` and `kmemory.c`, built on `std::alloc::Allocator` (stable in Rust 1.100).

Kohi's general-purpose heap: a freelist over one block, with memory tags, per-tag stats, debug guard bytes and a mutex.

Tags via a `heap.tagged(tag)` handle; `GlobalHeap<N>` makes it the program's `#[global_allocator]`.

**Open [`guide.html`](guide.html) for the full study guide**: the C and Rust code side by side, the differences, how to use it, and how to build it yourself.

| Path | What |
|---|---|
| `src/` | The Rust allocator (crate `kohi_dynamic`) |
| `original-c/` | The C it copies: `original-c/dynamic_allocator.{h,c}`, `original-c/kmemory.{h,c}`, with its licence |
| `examples/` | Runnable demo |
| `tests/` | Tests |
| `guide.html` | The guide (generated by `tools/gen_guides.py`) |
