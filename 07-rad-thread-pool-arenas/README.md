# RAD Thread Pool Arenas

Rust port of RAD linker `thread_pool.c` (`TP_Arena`), built on `std::alloc::Allocator` (stable in Rust 1.100).

One arena per worker thread for parallel jobs, saved and restored as a group.

Scoped threads each get `&mut` their own arena, so sharing an arena across threads is a compile error.

**Open [`guide.html`](guide.html) for the full study guide**: the C and Rust code side by side, the differences, how to use it, and how to build it yourself.

| Path | What |
|---|---|
| `src/` | The Rust allocator (crate `rad_tp_arena`) |
| `original-c/` | The C it copies: `original-c/thread_pool.{h,c}`, with its licence |
| `examples/` | Runnable demo |
| `tests/` | Tests |
| `guide.html` | The guide (generated by `tools/gen_guides.py`) |

```sh
cargo test -p rad_tp_arena
cargo run -p rad_tp_arena --example demo
```
