# Kohi Pool Allocator

Rust port of Kohi `pool_allocator.c`, built on `std::alloc::Allocator` (stable in Rust 1.100).

Fixed-size slots with a free list sorted by address, so the lowest free slot is reused first.

Fixes the C leak in `destroy`, the null dereference when full, and the self-loop on double free.

**Open [`guide.html`](guide.html) for the full study guide**: the C and Rust code side by side, the differences, how to use it, and how to build it yourself.
