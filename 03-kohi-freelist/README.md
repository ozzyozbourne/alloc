# Kohi Freelist

Rust port of Kohi `freelist.c`, built on `std::alloc::Allocator` (stable in Rust 1.100).

A first-fit tracker of free byte ranges that hands out offsets. The engine behind 04.

Not an `Allocator` on purpose: it works on offsets, so it can manage GPU memory too. Reports out-of-nodes and overlapping frees as errors.

**Open [`guide.html`](guide.html) for the full study guide**: the C and Rust code side by side, the differences, how to use it, and how to build it yourself.

| Path | What |
|---|---|
| `src/` | The Rust allocator (crate `kohi_freelist`) |
| `original-c/` | The C it copies: `original-c/freelist.{h,c}`, with its licence |
| `examples/` | Runnable demo |
| `tests/` | Tests |
| `guide.html` | The guide (generated by `tools/gen_guides.py`) |
